下面直接给你一套**可复制到前端做测试的用例**，全部围绕 **“星环智能教育公司发展史”** 这个主题设计，专门用于验证：

* 是否真的使用了知识库
* 是否会受字段约束影响
* 是否会根据目标和特殊要求调整 PPT 内容
* 是否在关闭知识库增强时出现偏差
* 是否会引用知识库中的关键锚点信息

我把它分成两类：**基础功能测试** 和 **RAG验证测试**。

---

# 一、基础功能测试用例

## 用例1：标准生成

**用途：** 验证基本流程能否正常生成教学设计/PPT

```json
{
  "学科": "信息技术",
  "课题": "星环智能教育公司发展史",
  "年级": "高一",
  "课时（分钟）": 10,
  "是否使用知识库增强": true,
  "知识目标": "了解星环智能教育科技有限公司的成立时间、创始人、总部地点以及主要发展阶段。",
  "能力目标": "能够梳理公司发展脉络，并总结企业在智能教育领域的阶段性成果。",
  "特殊要求": "内容结构清晰，适合课堂讲授，PPT控制在4页左右。"
}
```

**重点观察：**

* 是否出现“2020年3月15日”
* 是否出现“林泽远”
* 是否出现“杭州市未来科技城”
* 是否按发展阶段展开

---

## 用例2：短课时压缩版

**用途：** 验证课时变短后，内容是否自动精简

```json
{
  "学科": "信息技术",
  "课题": "星环智能教育公司发展史",
  "年级": "初二",
  "课时（分钟）": 20,
  "是否使用知识库增强": true,
  "知识目标": "了解星环智能教育公司的基本信息和重要发展节点。",
  "能力目标": "能够概括公司发展的主要阶段，并提炼关键信息。",
  "特殊要求": "课时较短，请压缩内容，突出公司成立、产品演进和关键事件，PPT控制在5页以内。"
}
```

**重点观察：**

* 页数是否变少
* 是否保留核心信息而删减次要细节
* 是否仍能保留关键知识点

---

```json

  "能力目标": "能够结合企业发展史分析智能教育行业的发展趋势，并形成结构化表达。",
```

* 是否增加“核心技术体系”“实验案例”等内容
* 是否有总结页、讨论页
* 是否层次更完整

# 二、RAG验证测试用例

## 用例4：强依赖知识库字段测试

**用途：** 验证是否真正读取知识库中的细节字段

```json
{
  "学科": "信息技术",
  "课题": "星环智能教育公司发展史",
  "年级": "高一",
  "课时（分钟）": 45,
  "是否使用知识库增强": true,
  "知识目标": "掌握星环智能教育公司的成立时间、创始人、产品代号及特殊验证信息。",
  "能力目标": "能够从企业发展资料中提取关键信息并进行归纳整理。",
  "特殊要求": "请重点呈现公司成立时间、创始人姓名、EduBrain X、蓝色松鼠计划等细节信息。"
}
```

**重点观察：**

* 是否出现“EduBrain X”
* 是否出现“蓝色松鼠计划”
* 是否准确使用知识库中的专有字段

这个用例很关键，因为“蓝色松鼠计划”不是常识，出现了就很能说明用了知识库。

---

## 用例5：关闭知识库增强对照测试

**用途：** 做 A/B 对照，验证开关是否真的生效

```json
{
  "学科": "信息技术",
  "课题": "星环智能教育公司发展史",
  "年级": "高一",
  "课时（分钟）": 45,
  "是否使用知识库增强": false,
  "知识目标": "了解一家智能教育公司的发展历程。",
  "能力目标": "能够概括企业发展的基本过程，并进行简单表达。",
  "特殊要求": "正常生成教学设计即可。"
}
```

**重点观察：**

* 是否不再稳定出现“林泽远”“蓝色松鼠计划”“2020年3月15日”
* 是否开始泛化为普通“教育科技公司发展史”
* 是否出现更强的模板化描述

这个用例建议和用例4对比看。

---

## 用例6：反常识字段测试

**用途：** 验证模型是否真的服从知识库，而不是靠常识乱改

```json
{
  "学科": "信息技术",
  "课题": "星环智能教育公司发展史中的重要事件分析",
  "年级": "高二",
  "课时（分钟）": 40,
  "是否使用知识库增强": true,
  "知识目标": "了解星环智能教育公司发展过程中的融资、产品发布和市场拓展情况。",
  "能力目标": "能够识别并整理企业发展史中的关键时间节点。",
  "特殊要求": "请严格以知识库内容为准，尤其关注首次融资时间、产品发布时间等信息，不要自行修正常识冲突。"
}
```

**重点观察：**

* 是否保留你知识库中的“公司首次融资时间：2025年”
* 是否擅自改成更“合理”的年份

这个用例专门测“模型服不服从知识库”。

# 三、教学目标差异测试

## 用例7：偏知识讲授型

**用途：** 验证知识目标主导时，内容是否偏“事实介绍”

```json
{
  "学科": "信息技术",
  "课题": "星环智能教育公司发展史",
  "年级": "高一",
  "课时（分钟）": 40,
  "是否使用知识库增强": true,
  "知识目标": "记住星环智能教育公司的成立时间、创始人、总部地点、产品发展阶段和关键事件。",
  "能力目标": "培养学生提取信息和整理时间线的能力。",
  "特殊要求": "请以知识讲授为主，增加时间轴展示。"
}
```

**重点观察：**

* 是否偏事实梳理
* 是否有时间轴
* 是否减少开放讨论

---

## 用例8：偏能力培养型

**用途：** 验证能力目标主导时，是否增加分析、归纳、表达环节

```json
{
  "学科": "信息技术",
  "课题": "星环智能教育公司发展史",
  "年级": "高二",
  "课时（分钟）": 45,
  "是否使用知识库增强": true,
  "知识目标": "了解星环智能教育公司的主要发展历程和关键成果。",
  "能力目标": "培养学生分析企业成长路径、归纳技术演进逻辑和进行课堂表达的能力。",
  "特殊要求": "请增加问题引导、阶段总结和学生讨论环节。"
}
```

**重点观察：**

* 是否增加“思考题”“讨论题”
* 是否从单纯介绍变成分析型结构
* 是否体现能力目标驱动

# 四、特殊要求约束测试

## 用例9：要求必须引用知识库细节

**用途：** 验证特殊要求是否能影响输出内容

```json
{
  "学科": "信息技术",
  "课题": "星环智能教育公司发展史",
  "年级": "高一",
  "课时（分钟）": 40,
  "是否使用知识库增强": true,
  "知识目标": "了解企业发展史中的基础事实和关键产品信息。",
  "能力目标": "培养学生从材料中筛选和验证信息的能力。",
  "特殊要求": "请在内容中明确体现：2020年3月15日、林泽远、EduBrain X、Adaptive Cognitive Engine、动态作业优化实验。"
}
```

**重点观察：**

* 是否命中全部指定字段
* 是否遗漏特定专有名词
* 是否能从知识库细节扩展为页面内容

---

## 用例10：要求面向低年级表达

**用途：** 验证语气和内容难度是否随年级变化

```json
{
  "学科": "信息技术",
  "课题": "星环智能教育公司发展史",
  "年级": "小学六年级",
  "课时（分钟）": 30,
  "是否使用知识库增强": true,
  "知识目标": "了解一家智能教育公司的成长过程和主要成果。",
  "能力目标": "能够按顺序讲述公司发展的几个重要阶段。",
  "特殊要求": "语言简单易懂，减少专业术语，多用分点表达，适合小学高年级学生理解。"
}
```

**重点观察：**

* 是否简化“自适应认知引擎”等术语
* 是否表达更口语化
* 是否保留知识库事实但降低讲解难度

# 五、配合参考资料上传的测试用例

## 用例11：知识库 + 参考资料联合测试

**用途：** 验证系统是否能同时利用知识库和上传资料

```json
{
  "学科": "信息技术",
  "课题": "星环智能教育公司发展史",
  "年级": "高二",
  "课时（分钟）": 50,
  "是否使用知识库增强": true,
  "知识目标": "了解星环智能教育公司的基础信息、产品阶段、关键事件和技术体系。",
  "能力目标": "能够整合知识库与参考资料中的信息，形成完整的企业发展史认知。",
  "特殊要求": "请结合上传参考资料和知识库内容共同生成，优先采用知识库中的核心事实，PPT需有资料整合页。"
}
```

**重点观察：**

* 是否同时使用两类信息
* 知识库与参考资料冲突时如何处理
* 是否出现“整合页”或“资料来源说明”
